# INFO 465 Final Capstone – Procurement & Equity Dashboard

Project Overview
*This is the final project for INFO 465. The goal was to create a working business intelligence solution that helps the Virginia Department of General Services (DGS) forecast procurement spending and monitor SWaM vendor engagement.

Built With
- Tableau Desktop (Mac)
- Excel Dataset: PrisonSampled2024.xlsx
- GitHub for version control and documentation

Architecture Summary
- Tableau dashboard with two interactive views:
  1. Forecasted monthly spend with 95% confidence interval
  2. Top 10 vendors by SWaM certification
- Filters: PO Category, Vendor State, SWaM status
- Clean layout and fiscal year formatting
